# Vision
## Goals
The goal of the Property Bidding Companion app is to create an experience that can be run prior to setting up a physical game of Monopoly that allows players to bid on a set of available properties.  This is meant to be a fun extension of the core experience, providing a novel mini-game as part of setting up the full game.

## Non-goals
The Property Bidding Companion app is only meant to affect game set up, not alter the core gameplay of Monopoly

## Target Audience
The target audience of this companion are players looking to extend the default rules and gameplay of the classic board game Monopoly to create new enjoyable experiences.

### User Personas
 - Joelle:  Joelle is a mother of two and finds the base game a bit too long for how much time she has.  She would like to find a way to make the game shorter that involves more skill than shuffling and dealing out properties at the start if the game.  In addition to playing the game for fun, she also sees it as a way to teach her children about budgeting and spending.

 - Issac:  Isaac is 14 and loves to play Monopoly, but often plays only with one other player (her older sister).  Isaac has found that whoever goes first usually wins in this setup, and she would like a way to make the game more "fair".

 - Durd:  Durd hosts a weekly social game night with his friends, and they usually play classic board games because they don't want to learn complex new rules.  At the same time, Durd would like to find ways to shake up the classic ruleset, while sill preserving the simplicity and social nature of the games.

# Functional Requirements

## Technologies
 - The app is a web app meant to run in a browser
 - The app must use Vite as the build tool and development server
 - The app must use pnpm for package management
 - The app must be written in React and Typescript

## Form Factors
 - The app is intended to be used primarily on mobile devices and must support the following screen resolutions in both portrait and landscape modes:
    - 750 x 1334
    - 1080 x 2340
    - 1179 x 2556
    - 1290 x 2796
